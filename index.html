01

Context space adaptation

01.1

Context space memory

Memory is the interaction history: the recent observations, and the action notes describing what the actor sent and what came back.

Without / with memory is whether that history is included in the actor’s context.

Same model, same task statement. The only difference is what the previous calls left behind.

01.1.1

Memory for temporal reasoning: what the last attempt changed

Across three fine-manipulation tasks the same model goes from 0/9 to 8/9 once the interaction history is carried forward.

Memory lets an attempt be read against the one before it. Without it every call is a first attempt: an action can be repeated, but not recognised as already taken, and its effect is not available to the call that follows. With it, the attempt and its measured effect are both in view, so the next command can be a correction rather than a repeat.

01.1.2

Memory for spatial reasoning: object relations and pose

Memory helps with understanding of relationships between objects, and object pose.

A frame shows where things are. It does not show how an object responded to being moved. Carrying the previous command together with the measurement it produced makes that difference available, so support, contact and orientation can be reasoned about rather than read off appearance.

01.2

Context steers execution and recovery

Human demonstration as context: a human recording of the task is supplied; the model selects frames from it, as a description of what the task is.

Human feedback as context: a human intervenes during the run and uses language to guide the next decision.

Both change the behaviour, and what they contain decides how.

A demonstration supplies the shape of the task. The run imitates what the recording does — how the task is carried through, and, when the recording shows one, how a bad placement is recovered from.

Feedback supplies a judgement the run cannot make about itself, and arrives in time to change the next decision.

02

Framework

Memory and context steering show the same thing: context-space adaptation guides how the robot interacts with its environment.

So we design a harness that provides feedback from physical experience in context space. The actor keeps one job: one grounded tool call per decision. A planner holds the task structure. An experience module reads the recent interactions, measures the effect the actor cannot see, and returns a feedback line.

03

From physical experience to context space adaptation

Planning provides task-level structure for reasoning and execution. The planner decomposes the task into subtasks and proposes a method for the current one. Through the experience module, this structure helps guide task-level reasoning and informs the selection and application of relevant lessons when generating feedback for the next action.

Physical experience becomes reusable guidance in context space. The experience module retains lessons learned from physical interaction together with their applicability conditions. When a relevant situation arises, it reuses those lessons to provide feedback for the next action, bringing prior experience into the current decision through context.

05

Limitations

The agent changes viewpoint, tests engagement, diagnoses slip and reindexes the held key. Yet visual alignment and successful arm motion do not establish stable seating or screw tightening.

06

Takeaway

Robots can adapt their behavior in context space by retaining physical interaction history, incorporating demonstrations and feedback, organizing task execution, and reusing lessons learned from physical experience.

Context enables adaptation through memory of physical interaction. Retaining physical interaction history supports temporal reasoning about what previous attempts changed and spatial reasoning about object relations and pose, informing the robot’s next decision.

Context steers how the robot acts. Demonstrations and language feedback guide execution and recovery, making context a practical interface for adapting behavior.

Planning provides task-level structure for reasoning and execution. The planner defines subtasks and methods that, through the experience module, guide task-level reasoning and the selection and application of relevant lessons.

Physical experience becomes reusable guidance in context space. The experience module retains lessons and their applicability conditions, then reuses relevant lessons to guide the next action through contextual feedback.
